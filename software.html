Open software

Methods should be useful beyond one lab.

We develop practical, open tools for amplicon and shotgun metagenomics, community analysis and genome-resolved microbiology. Each project is maintained in the open, with source code and documentation available through its repository.

Browse the group GitHub ↗

Pipelines

End-to-end analysis, made practical.

These workflows carry data from reads to interpretable results. They bring established methods together with the lab’s quality control, reproducibility and microbial-analysis expertise.

Pipeline 01

LotuS3

A lightweight, fast and configurable pipeline for 16S, 18S and ITS amplicon sequencing. It brings several established denoising and clustering approaches into one workflow while retaining room for careful configuration.

828 Bioconda downloads

★ 1 GitHub star

Pipeline 02

MATAFILER4

A Linux and HPC-oriented pipeline for raw shotgun metagenomic reads. It supports assembly-dependent workflows alongside assembly-independent taxonomic and functional profiling for complex communities such as soil.
